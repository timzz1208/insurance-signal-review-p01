## 每個場景的動態事件

1. **開場**：標題在第 0 格就已經寫到一半。學生頭上的朱紅「?」泡泡一顆顆飛向老師，越堆越多。「而是有一天」時泡泡全部消失，中央出現一張「問題」卡：先被切成四塊、分開，再逐塊打勾；學生頭上出現青綠「!」，老師往後退一步。
2. **四格拆題**：紙上畫出「現況／目標／障礙／限制」四格。學生的筆依旁白依序寫進前三格。便利貼分類：兩張「能動」貼進障礙，一張上鎖的「暫時不能動」貼進限制。老師的筆只進來一次，留下一張「提示」就離開。
3. **知道很多 vs 教給這個人**：左邊書一本本疊高，紙張飛向學生、把學生淹沒；右邊的解題單上，老師圈出唯一卡住的第 ③ 步，貼上「換一種說法」，「?」變成打勾。底部三條路徑，各自卡在不同的位置。
4. **先問不先答**：「答案」卡翻面變成「?」並移開；三個提問泡泡依旁白彈出；蝸牛在「一開始比較慢」時慢慢爬過，「下次再問老師」被劃掉；「拆問題→判斷→試做→修正」循環依序畫出，青綠點持續繞圈；「下一題」「下一個工作」兩張卡滑入，並蓋上同一個循環圖示。
5. **扶一段再放手**：先把「答案販賣機」和「丟著不管」打叉；接著老師牽著學生走一段、放手、指方向，學生自己走完，腳印留在路上。學生把「這一步我卡住了」泡泡帶回給老師。最後一句出現時，腳印轉成青綠色（教學留下來）。片尾 CTA：「下次教人之前，先請他說出」四項檢查表逐項打勾，停留約 4 秒，並列出資料來源。

顏色分工：**青綠**＝學習者自己的路（自主、拆題、方法）；**朱紅**＝依賴（每題都問、答案機器、卡點）。
