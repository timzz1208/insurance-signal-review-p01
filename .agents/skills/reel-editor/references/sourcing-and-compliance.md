# 真實案例、數字與合規

## 找案例
1. 先用目標語言搜尋新聞（中文、日文、英文）。旅遊保險類的案例，**日本保險公司公開的「保険金お支払事例」**最容易找到，而且有金額。
2. 優先順序：保險公司或官方公開的資料 > 正式新聞 > 比較網站 > 論壇或社群貼文。論壇貼文不要放進影片。
3. **核對原文**：WebFetch 的摘要可能抄錯數字，要用 `curl -sL -A "Mozilla/5.0" URL` 抓原始網頁，用 grep 找出關鍵句和金額。
4. 兩個來源的數字不同時（例如 12,438,470 和 2,438,470），採用一手來源，並告訴使用者有落差。
5. 找不到「完全符合」的案例就直說。可以改用「同類保障」的真實案例，但字卡上要標明，例如「日本海外旅行保險之個人賠償責任」。

## 數字呈現
- 外幣換成台幣：寫「約新台幣 X 萬元」，旁邊附「原始金額＋匯率＋年份」。查最新匯率時要附上來源。
- 開頭的數字跳動要標明「真實理賠案例・換算新台幣」，不能讓人以為是影片故事裡的金額。

## 保險內容用語
- 不說「一定賠」或「保證理賠」，改用「可以申請理賠」，並加上「以保險金額為上限，可能有自負額」。
- 片尾和貼文都要放：「示意案例，實際承保範圍、限額及除外責任依保單條款為準。」
- 要提醒的除外：「自己入住的客房、借用物品」常常另有約定或不保，樓下別人的房間才是典型的第三人損失。
- 出現保險公司名稱（引用來源時）或金額時，要提醒使用者：發布前必須先做公司合規確認。

## 來源整理檔
每支影片都要輸出 `案例來源.md`：來源名稱、網址、原文關鍵句、中文翻譯、換算方式、數字落差說明，以及找不到的部分。
