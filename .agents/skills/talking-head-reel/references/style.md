# 視覺風格

- 字型：Noto Sans CJK TC（思源黑體）。大字 Black 900，內文 Bold 700。
- 色票：黃 `#FFD60A`（主色／強調）、紅 `#FF3B30`（錯誤／衝突）、白 `#FFFFFF`、背景 `#0E0F12`、面板 `#17191E`、次要文字 `#9AA0AA`。
- 一支 30 秒影片：大字卡 3–5 張、說明畫面 1–2 段為上限。每個效果都要有目的（強調、轉折、補充資訊），不要每秒都塞效果。
- 動畫語言：彈簧回彈（spring）、甩鏡轉場（whip，0.3s 加動態模糊）、逐字出現。
- IG 安全區：頂部 ~200px、底部 ~400px、右側 ~120px 會被介面蓋住。封面在個人頁格子會被裁成 4:5（y 285–1635）。
- 輸出：H.264 High、yuv420p、30fps、6 Mbps 上限、AAC 160k、−14 LUFS、真峰值 ≤ −1 dBFS。
