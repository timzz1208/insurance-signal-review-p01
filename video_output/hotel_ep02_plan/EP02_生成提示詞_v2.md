# EP02 生成提示詞 v2（重新生成用）

## 第一批的問題，以及這版怎麼改

| 問題 | 原因 | 這版的做法 |
|---|---|---|
| 臉每個鏡頭都不一樣 | 模型自己生成臉，或首幀和動作差太多 | **有臉的鏡頭只留 3 個**，每個都用你本人的照片做首幀；其他鏡頭改拍手、背影、物件 |
| 笑容誇張、表情僵 | 提示詞寫「開懷大笑」 | 改成「嘴巴閉合的自然微笑」「眼神看向畫面外」 |
| 人物直視鏡頭 | 沒有限制視線 | 每個鏡頭都寫「不要看鏡頭」 |
| 看不到水 | 水在遠景裡太小，模型會省略 | 水的鏡頭全部改成**特寫或微距**，水佔畫面一半以上 |
| 畫面靜止 | 鏡頭裡沒有動作 | 每個鏡頭都有一個明確的動作，加上緩慢運鏡 |
| 字和分割畫面已經燒進畫面 | 生成或剪輯時加的 | **只給我乾淨的素材**，不要字、不要分割畫面，後製我來加 |
| 沒有聲音 | 這批輸出沒有音軌 | H3 可以生成聲音就打開；不行的話，見最後一節「聲音」 |

## 共同設定

**每一則提示詞前面都加：**
> 9:16 直式，寫實電影感，35mm 鏡頭，自然光，柔和對比，輕微手持晃動，淺景深，真實皮膚質感，動作自然緩慢。

**每一則都加上負面提示詞（不要出現的東西）：**
> 文字、字幕、Logo、招牌、浮水印、分割畫面、變臉、五官扭曲、多餘或缺少手指、誇張大笑、露出整排牙齒、直視鏡頭、表情僵硬、塑膠皮膚、過度磨皮、魚眼、畫面靜止不動、洪水、爆管

**長度**：每個鏡頭 3 到 5 秒就好。越短越穩定。

**首幀**：有你出現的鏡頭（G1、F1、L1），先用你的照片做出一張「已經在那個場景、擺好那個姿勢」的首幀圖，再拿去生成影片。不要直接拿大頭照當首幀，否則模型會在動作中把臉改掉。

## 聲音

這批影片沒有音軌。我建議這樣處理：

1. **你的三句台詞自己錄**：「先去吃早餐，回來再泡！」、「喂？」、「對不起……這要怎麼賠？」。主角就是你，用自己的聲音最自然。用手機在安靜的房間錄，離嘴巴大約 20 公分，每句錄三次。
2. **主管的台詞**（「先生，您房間的水，流到樓下客人的房間了。」）：請朋友錄，或用你的 AI 配音工具。
3. **環境音**：如果 H3 可以生成聲音，打開它；不行的話，水聲、敲門聲、手機震動、滴水我可以合成。**早餐廳的人聲環境音**合成不出來，需要你找一段免費授權（CC0）的素材，或用 H3 生成。
