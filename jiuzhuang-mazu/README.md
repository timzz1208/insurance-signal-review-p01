## 製作方式

| 項目 | 做法 |
|---|---|
| 畫面 | `render/lib.js` 可重複使用的 SVG 元件（山、雲、樹、客家屋、人物姿勢、媽祖像、神轎、香爐、燈籠、筊杯、鑼、鞭炮、煙火…），`render/scenes.js` 14 個場景 |
| 線稿風格 | `pathLength=1` + dash offset 做「邊畫邊出現」；每 3 格換一次種子的 `feTurbulence` 位移濾鏡做手繪抖動；米白紙纖維紋理（夜景為深藍紙） |
| 遮擋 | 所有實體物件都是封閉路徑，並填上紙色，由後往前繪製，所以後方線條不會穿透人物或建築 |
| 鏡頭 | 每場景緩慢推移/平移；場景間 1 秒交叉溶接 |
| 配音 | 見下方「配音說明」；`tools/asr_check.py` 用離線語音辨識回聽校對讀音 |
| 時間軸 | 先生成全部旁白並量測秒數，再由 `tools/tts.py` 推算每場景長度，存進 `build/timeline.json`；畫面、字幕、音效都讀同一份時間軸 |
| 配樂 | `tools/audio.py` 以程式合成古箏（Karplus-Strong 撥弦）、笛子、大鼓、大鑼、小鑼、鈸、梆子、磬，五聲音階（D 宮調）並有媽祖主題動機 |
| 音效 | 雨、雷、溪水、蟲鳴、木門、筊杯落地、鞭炮、鑼、煙火升空與爆炸、人聲、炒鍋、紙卷、蓋印 |
| 混音 | 旁白出現時音樂自動壓低 10 dB、音效壓低 5 dB，整體 -15 LUFS，峰值 ≤ -1.5 dBFS |
| 渲染 | Headless Chromium：每格先組好 SVG，等兩次 `requestAnimationFrame` 確認版面與繪製都完成才截圖，再用 PNG 無損送進 ffmpeg |
| 品管 | `tools/qa.py` 逐格解碼檢查空白或單色畫面、純黑/純白破圖區塊、凍結畫面、非轉場的突兀跳動，並核對總格數 |

### 配音說明

指定的 VoAI TTS（子墨／Neo／穩健）在這次的執行環境中無法連線：網路政策封鎖了 `voai.ai`、`connect.voai.ai`，環境裡也沒有 VoAI API 金鑰。
所以目前的版本改用離線的 Kokoro v1.1-zh（sherpa-onnx）沉穩男聲 `sid 67`，語速 0.92。
要換回 VoAI，只需把 `tools/tts.py` 的 `tts.generate(...)` 改成呼叫 VoAI API 並寫出同樣的 `build/vo/NN.wav`，再執行 `./make.sh`。
時間軸、字幕、配樂會自動依新的秒數重新排好。
