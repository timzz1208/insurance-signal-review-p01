# 視覺語言：紙與墨

> 製作者：林彥廷｜timzz1208@gmail.com

## 為什麼是「紙與墨」

「家庭責任流」的第一版用深藍底加橘藍發光，被評為廉價、有 AI 感。原因有五個：

1. 深藍加發光是 AI 生成科技畫面最常見的配色
2. 每個元素都發光，沒有主次
3. 只用一種粗黑體，沒有字體對比
4. 背景是空的漸層，沒有材質
5. 每個動作的節奏都一樣

改成「紙與墨」之後，質感明顯提升。**下面這些是風格的核心，換主題時不要拿掉。**

## 不能拿掉的元素

| 元素 | 做法（engine.js） | 作用 |
|---|---|---|
| 紋路紙 | `buildPaper()`：纖維、雜點、不均勻光、四周略暗 | 材質感，告別空白漸層 |
| 定格顆粒 | `finish()`：顆粒每秒跳 12 次（3 張輪流） | 像定格印刷，畫面一直有「活」的質感 |
| 網點 | `bucket()`：液體用網點，越深點越大 | 用印刷語言取代發光 |
| 木刻斜線 | `tank()`：存款用斜線填滿 | 和網點做出材質對比 |
| 朱紅印章 | `stamp()`：「家」字印章，邊緣有磨損 | 視覺焦點與品牌記憶點 |
| 套色錯位陰影 | `bucket()` 的壓力陰影偏移 12px | 印刷的層次感 |
| 墨點粒子流 | `stream()`：用 multiply 疊色的橢圓墨點 | 流動是主角，但不發光 |
| 雜誌版頭 | `furniture()`：左上欄名、右上帳號、雙線 | 編輯感、可信度 |

## 配色

| 角色 | 色碼 | 用在哪 |
|---|---|---|
| 紙 | `#ECE8DF` | 底 |
| 墨 | `#1D1F25` | 主色：線、字、粒子 |
| 淡墨 | `#55565C`、`#7B766C` | 次要文字、說明 |
| **朱紅** | `#D8432A` | 唯一的強調色：責任、中斷、缺口、重點數字 |
| **群青** | `#2C4C9E` | 轉折色：**故事轉折時才第一次出現**（例：保障緩衝） |

- 同一個畫面，強調色不要超過兩處重點。
- 轉折色提早出現，轉折就沒有份量。
- 想換強調色時，只改 `COL.verm`（強調色）和 `COL.blue`（轉折色）。紙、墨、顆粒都保留。

## 字體

- 標題：思源宋體 Black（`Noto Serif TC` 900），76～92px。大數字 188px。
- 標籤、說明：思源黑體（`Noto Sans TC` 500～800），24～38px。
- **一定要有宋體和黑體的對比**，只用一種粗黑體會很廉價。
- 標題分行錯開出場（每行晚 0.12 秒、從下方 20px 浮上來）。

## 版面（1080×1920）

| 區域 | 位置 |
|---|---|
| 版頭 | y 196～221（左欄名、右帳號） |
| 標題 | x 110，y 300 起，行高 92 |
| 主畫面（網絡、水桶） | y 560～1340 |
| 數字列 | y 1336～1530（左右兩欄＋一句說明） |
| 示意聲明 | y 1580 |
| 左右邊界 | x 110～970 |

重要文字保持在上下 250px 以內；右下角留給 IG 的按讚、留言按鈕。

## 動態節奏

- **輕重有別**：劃斷（重擊＋震動 14px）、數字砸下（放大 1.9 倍、回彈、震動 10px）、標題出場（輕）、點擊（波紋）。
- 每個動作的節奏都一樣會很單調。重要時刻要有停頓，或讓畫面先安靜一下。
- 鉤子公式：**提問 → 視覺斷裂 → 巨大數字砸下**，前 2 秒內完成。
- 震動用固定公式（`shake()`），同一秒永遠一樣，可以重現。

## 避免

- 深色底加霓虹、發光、漸層光暈
- 所有元素都在動、都在閃
- 一整頁文字（要靠畫面說故事）
- 從黑畫面淡入的開頭
