# 受眾、題材與發布（吸引客戶，而不是同業）

> 製作者：林彥廷｜timzz1208@gmail.com
> 來自實際發布的經驗：「家庭責任流」在 Threads 上 1.8 萬瀏覽、386 次分享、持續漲粉，但新粉多是同業與 AI 創作者。
> 開工前先問使用者：**這一支要給客戶看，還是給同業／AI 受眾看？** 兩條線分開做，不要混在同一篇。

## 1. 怎麼判斷一支內容會吸到誰

| | 吸引同業 | 吸引客戶 |
|---|---|---|
| 答案是什麼 | 一種保險或工具（同業拿去當銷售素材） | 觀眾自己家的狀況 |
| 觀眾看完會 | 收藏，拿去講給自己的客戶聽 | 算算自己家，轉給另一半或家人 |
| 留言 | 「好用」「求模板」「怎麼做的」 | 「我家剩 15 年」「月底真的是 0」 |
| 文案主角 | 工具、AI、方法 | 觀眾的生活場景 |
| hashtag | 產業詞（#保險觀念 #保險知識 #風險管理 #財商 #險種名） | 人生階段（#房貸族 #首購族 #新婚 #小家庭 #雙薪家庭 #新手爸媽） |

同業多不是壞事：之後可以發展教學、工作坊、增員。只是要知道自己在經營哪一條線。

## 2. 題材評分（客戶線）

每項 1～5 分：

1. **封面鉤子**：前 2 秒能不能用一個數字或反差句抓住人
2. **自我對照**：觀眾看完，會不會想算自己家、留言自己的數字
3. **分享對象**：會轉給另一半或家人（客戶題）？還是轉給同事、同業（同業題）？
4. **可視覺化**：能不能拆成幾個場景，每個場景都有一個會動的事件
5. **可查證**：數字有沒有官方出處（例如主計總處家庭收支調查）；沒有就明講是示意
6. **不提商品**：不需要任何商品或公司名稱就講得完

加分：**時效**（近期新聞、新制度、年終、報稅季）。

「收藏價值」不再當主要指標：收藏是同業最常做的動作，用它挑題目會一直挑到同業題。

## 3. 內容配比

- 約七成：**家庭的錢**（月底為什麼是 0、雙薪家庭的錢流去哪、養孩子到 22 歲、爸媽退休誰養誰、年終先去哪）。答案是觀念或做法，不是產品。用來吸引客戶、建立信任。
- 約三成：**保障觀念**（收入中斷、房貸、醫療自費）。可以提險種**類別**，但要講清楚保障範圍與限制（compliance.md）。
- 另外一條：**幕後**（AI 怎麼做、改版前後、三個版面提案）。給同業／AI 受眾，獨立發，不跟客戶線混在同一篇。

## 4. 文案與 hashtag（客戶線）

- **開頭講生活，不講工具**：「買房那天，我們都在算頭期款……但很少人算過這一題👇」
- **不提 AI**，也不把險種名放在第一句。
- **行動呼籲用「分享」**：「📩 傳給一起繳房貸的那個人」「💬 你家還剩幾年？留言一個數字就好」。分享到私訊是推給非追蹤者最強的訊號；收藏則多半來自同業。
- **Threads 口吻更口語**，像在聊天，3～6 行就好，最後一句是問句。
- **hashtag 用人生階段＋地區**：#房貸族 #首購族 #買房 #新婚 #小家庭 #雙薪家庭 #新手爸媽 #家庭理財 #台中買房（依客群）＋系列標籤（例 #家庭日報）。
- 文案最後保留示意聲明；提到險種類別時，附上保障範圍的說明。
- 範例：`mortgage-flow/IG_caption_客戶版.md`（工作分支上）。

## 5. 劇情：解法要「看得見」

- 前面每個選擇都有具體代價，解法就不能只是一張抽象圖。
- 有效的結構（房貸責任流 B 版）：**倒帶回封面 → 蓋「換版」章 → 同一個斷裂再發生一次 → 這次有東西接住 → 前面三個代價逐一打勾劃掉 → 一句可截圖的口號**。
- 結尾讓觀眾算自己：「你家剩幾年？乘上每月房貸，就是要接住的數字。」

## 6. 發布後怎麼確認

- IG 洞察報告：非追蹤者比例、**分享 vs 收藏**、年齡與地區。收藏遠多於分享、觀眾多是追蹤者 → 多半是同業循環。
- 點開最近 20～30 個新粉：多是業務、AI、創作者帳號 → 同業線；多是一般帳號 → 客戶線。
- 擴散：限動加投票（「你家房貸還剩幾年？」）；找非同業帳號共同發布（房仲、室內設計、親子、新婚）；投放時鎖定 28～40 歲、興趣買房或育兒。
