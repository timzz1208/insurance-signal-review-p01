# 保險、財經內容紅線

> 製作者：林彥廷｜timzz1208@gmail.com

做保險、財經、家庭財務題材時，每一項都要做到：

- [ ] **只用虛構家庭與示意數字**。不放任何客戶資料，也不用真實案例改寫。
- [ ] **不出現**保費、保額、商品名稱、公司名稱。
- [ ] **不出現**「一定理賠」「買了就沒事」「保證」這類承諾性說法。
- [ ] 畫面上**全程**標示「虛構家庭與數字，僅為示意」（範例放在 y 1580）。
- [ ] 結尾聲明：「虛構家庭與數字｜示意動畫，不代表特定商品、核保結果或給付承諾」。
- [ ] 結語指向「先釐清需求、再確認正式的保障方向」，不要叫觀眾直接購買。
- [ ] 如果引用公開數據（例如統計資料），寫出出處，並附在說明文字裡。
- [ ] 內容定位是**觀念分享**：講的是一類保險或理財工具的特性，不是特定商品。若你所屬單位對社群內容另有規定，依規定辦理。
- [ ] 提到險種類別（例如「房貸壽險」）時，一定寫清楚保障範圍與限制（例如「主要保障身故、完全失能；失業不在保障範圍」），用「常見設計」而不是「一定」。
