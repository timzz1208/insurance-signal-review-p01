# 家庭責任流（paper-ink-flow 範本作品）

> **製作者：林彥廷**｜timzz1208@gmail.com（有問題歡迎來信）｜IG：@timzz1208
> 「收入中斷時，誰接住這些責任？」的 IG 9:16 動態影片與互動模擬器。所有家庭、數字都是虛構的示意。

這個資料夾是 `paper-ink-flow` skill 的範本，也是可以直接重做出原片的完整原始碼。換主題時請照 skill 的 `references/method.md` 修改。

| 檔案 | 用途 |
|---|---|
| `video.html` | 影片動畫；在瀏覽器打開可以預覽、暫停、拖曳時間軸 |
| `engine.js` | 影片與互動版共用的繪圖引擎（紙張、顆粒、粒子流、水桶、節點、印章） |
| `interactive.html` | 互動模擬器：調整虛構數字、切換中斷情境、比較四條路 |
| `render.js` | 逐格輸出 `video.html` → MP4（本機字型、先收集字再預先載入） |
| `sound.py` | 合成音效與配樂、放置旁白、ducking 混音，時間點對齊畫面 |
| `make.sh` | 完整流程：畫面 → 音效＋旁白 → 合成 → 檢查 |
| `tools/voice_lines.py` | 從整段旁白量出每句的起訖秒數 → `VOICE_LINES` |
| `tools/sync_check.py` | 檢查 `video.html` 與 `sound.py` 的 `TIME_MAP` 是否一致 |
| `tools/check.py` | 成品檢查：解析度、fps、長度、檔案大小、音量 |
| `voice/lines.txt` | 旁白稿（一句一行）；旁白音檔請存成 `voice/narration.wav` |

## 視覺方向：紙與墨

有纖維的紙底、墨黑主色、朱紅代表家庭責任；群青只留給「緩衝」，最後才第一次出現。
不用發光，改用網點（水桶）、木刻斜線（存款）、朱紅印章（家）與定格顆粒做質感。
標題用思源宋體 Black，標籤用思源黑體。

## 旁白版時間軸

旁白總長約 33 秒，所以畫面依旁白拉長到 39.5 秒。`video.html` 與 `sound.py` 共用同一張 `TIME_MAP`，
把真實時間對應到原本 30 秒的劇情時間；劇情照比例拉長，粒子與水波仍用正常速度流動。
下表的秒數是原本 30 秒版的劇情時間。

| 旁白 | 放置時間（秒） |
|---|---|
| 如果明天沒有薪水， | 0.15（念完後 2.05 劃斷） |
| 林家每個月，會少四萬。 | 2.65 |
| 收入停了，房貸、學費、生活費，一樣都不會停。 | 5.45 |
| 這時候，只能選。 | 10.85 |
| 動用存款？六十萬，撐十五個月就見底。 | 12.70 |
| 賣掉房子？缺口變小，但要搬家、孩子轉學。 | 18.70 |
| 讓另一半多扛？缺口還在，人也會累。 | 22.80 |
| 如果事先準備好緩衝，缺口先有人接住，家人就有時間好好決定。 | 27.20 |
| 先說清楚要守住的生活，再確認正式的保障方向。 | 34.20 |

旁白說話時，音效與配樂自動壓低約 11 dB，說話時人聲比背景大約 12.6 dB。

## 影片分鏡

| 秒數 | 畫面 |
|---|---|
| 0–0.9 | 封面即鉤子：「如果明天停薪，你家撐得了幾個月？」水流已經在跑 |
| 0.9–3.4 | 主要收入被朱紅斜線劃斷、墨點噴散、畫面一震；「−40,000 元」砸進畫面 |
| 3.4–7.4 | 「收入停了，責任不會跟著停。」三個水桶轉朱紅、水位下降 |
| 7.4–20.2 | 三個選擇依序被點開：動用存款（15 個月歸零）、賣掉房子（多了房租，要搬家）、另一半多扛（缺口變小，但要長期兼職） |
| 20.2–25.6 | 群青的「保障緩衝」補上中斷的位置，水流重新接上，存款留著 |
| 25.6–30 | 結語「先說清楚要守住的生活，再確認正式保障方向。」＋ @timzz1208 ＋ 示意聲明 |

## 音效設計

全部用程式合成，聲音語言配合紙與墨：

| 秒數 | 聲音 |
|---|---|
| 0–0.9 | 小調和弦墊底、兩下時鐘滴答、墨點流動的細碎聲 |
| 0.9 | 兩道筆劃刮過紙、低頻一沉，和弦瞬間抽掉 |
| 1.3 | 「−40,000」落定：深沉低頻＋紙面拍擊 |
| 1.9–2.4 | 水桶轉紅，三個往下走的木琴音；之後低調的緊張持續音 |
| 8.2–20.2 | 每次點擊一聲木質敲擊；存款每少一個月一聲滴答（音高往下）；歸零時空洞的一聲；房貸桶流空的下滑音；另一半的心跳 |
| 21.4 | 緩衝出現：溫暖的鐘聲大三和弦，墊底轉成大調 |
| 25.8–27.2 | 四行字各一道筆劃，印章落下，收在 C 大調 |

```bash
python3 sound.py sfx.wav --voice narration.wav --mix mix.wav   # 需要 numpy、scipy
ffmpeg -i 無聲影片.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest family-flow-ig.mp4
```

## 重新輸出

```bash
npm install                                   # 字型（@fontsource/noto-sans-tc、noto-serif-tc）＋ playwright
pip install numpy scipy imageio-ffmpeg
node render.js --frames 0.3,2.5,9,15,21,28,36  # 先看定格（build/stills/）
bash make.sh                                  # 完整輸出 → output/
```
