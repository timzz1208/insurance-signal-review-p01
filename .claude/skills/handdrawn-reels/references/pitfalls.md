# 踩雷紀錄（症狀 → 原因 → 解法）

每一條都在實際製作中發生過。開工前讀一遍；遇到怪問題時先來這裡找。

### 環境
1. **找不到前作資料夾** → 前作在別的分支，沒有 merge 進 main → 用 `git fetch --all` 加 `git log --all --name-only` 找到分支，再用 `git archive` 唯讀取出。
2. **Playwright 啟動失敗（browser 版本不合）** → 預裝的是 `chromium-1194`，新版 playwright 會找別的版本 → `npm install playwright@1.56.1 --save-exact`。不要執行 `playwright install`。
3. **WebFetch 抓政府網站和多數新聞網站都被擋（EGRESS_BLOCKED）** → 雲端環境的網路政策限制 → 改用 WebSearch 的摘要，拿官方頁面和多家媒體交叉比對，並**在 README 和回報裡明講這個查證限制**，建議使用者發布前再到官網確認一次。
4. **`pkill -f "http.server 8765"` 讓整個指令以 exit 144 結束** → 這個字串也出現在執行 pkill 的那個 shell 自己的指令列，pkill 把自己也殺了 → 不要用 `pkill -f` 比對同一行指令裡的字串。改用 PID，或讓伺服器用 timeout 自己結束。
5. **字型測試頁顯示亂碼或 fallback 字型** → 用 `file://` 開頁面時 @font-face 讀不到；頁面也少了 `<meta charset="utf-8">` → 用本機 http server 開，並加上 charset。
6. **系統一直提示「檔案在磁碟上被改過」** → 有時是誤報 → 先跑 `git status`／`git diff` 確認，沒有差異就照常工作，不要把檔案還原。

### 字型與文字
7. **「為／真／內／值」顯示成「爲／眞／内／値」** → 霞鶩文楷 TC 採用舊字形 → 改用芫荽 Iansui（教育部標準字形）。**做字形對照圖時要用真實字型渲染再比對，不能只看原始碼裡的字元。**
8. **芫荽沒有粗體** → 字型只有一種字重 400 → 粗體用同色描邊做：`stroke=<同色>`、`stroke-width = 字級 × 0.035`、`paint-order="stroke"`、`stroke-linejoin="round"`；`measure()` 的寬度也要加上這個描邊寬。
9. **手寫揭露時，「誰付？」的「言」字旁被切掉**（使用者抓到的） → clip 矩形寫死 250px 寬，但 92px 字實際約 285px → **clip 或 mask 的範圍一律用 `measure()` 算出的實際字寬，左右各留 20px 以上**，並把字縮到放得進容器。寫死的像素寬度就是 bug。
10. **來源小字換行時把「10,434.4／7」拆成兩行** → 逐字換行 → 改成以 token 為單位換行：`/[0-9A-Za-z.,\/]+|./gu`，數字和英文連在一起不拆；閉合標點不放在行首。
11. **加上帳號＋系列名後，碰到第 4、5 張最上面那行字** → 左上角的空間只夠放帳號 → Reels 只放 `@timzz1208`，卡片再放完整的 `帳號 ｜ 系列名`。任何固定圖層加上去之後，都要把所有場景的最上方區域裁出來檢查。

### 動畫與版面
12. **第 0 格是空白紙**（QA：near-uniform，凍結 7 格） → 封面數字從畫面外開始落下 → Reels 的第 0 格就是縮圖，也是前 2 秒的鉤子，**第 0 格一定要看得到內容**。讓物件在 t = 0 時已經落到一半。
13. **三行大數字落下時互相穿過** → 每一行分開落下，後落的會經過前一行的位置 → 整組數字一起落下、一起震，再逐位滾動定格。
14. **有 0.2 秒幾乎靜止**（QA：frozen） → 下一個筆畫用 ease-in 開始，前幾格幾乎沒動 → 接續的筆畫用線性進度，或提早開始，讓畫面持續有東西在動。
15. **最後一個「重擊」比最後幾位數字還早出現** → 手算位數時寫成 13，實際是 16 → **所有次數、時間都用程式從資料算出來**（例如用計數器 `g` 累加），不要手寫常數。
16. **封面大數字超出右側安全區** → 字級 200 太大 → 降到 178，並用 guides 截圖確認（右邊界 x = 960）。
17. **趨勢箭頭壓到「↑」和長條圖數值標籤**（修了兩次才對） → 只看縮圖調座標 → 先算出各元素的 bbox（標籤底線、數值 y = 柱頂 − 14），把箭頭放進中間的空帶，再裁原尺寸確認。
18. **水桶上的「現金流」壓到水位線** → 標籤放在會變動的水位範圍內 → 標籤移到桶子下方的地面。
19. **落地式大傘底部畫出一個手把彎勾** → 共用元件預設會畫手把 → 元件加 `stand` 選項，關掉手把、把傘柄延伸到地面。
20. **雨在手機上幾乎看不見** → 線寬 1.6、透明度 0.42、110 滴 → 改成線寬 2.2、透明度 0.5、170 滴。雨滴打到傘面會停住並濺起水花（碰撞用和畫傘面同一個 `surf(x)` 函式）。
21. **警示色被濫用的風險** → 朱紅只能用在自費、差額、缺口、「掉到你家裡的那一塊」、「哪些沒有」。劃掉「保多少？」用墨色，答案「誰付？」用主色。

### 聲音
22. **WAV 峰值 -1.5，MP4 卻變成 -0.5 dBTP** → AAC 編碼會讓真峰值上升約 1.8～2 dB → limiter 上限設 **-4.2 dBFS**，並**用 `ffmpeg ebur128=peak=true` 量成品 MP4**。這次成品為 -15.1 LUFS／-2.3 dBTP。
23. **pyloudnorm 量 -15.0，ffmpeg 量成品是 -15.1～-15.3** → AAC 編碼和量測方法的差異 → 可以接受，README 同時寫兩個數字。
24. **ASR 相似度只有 81%，擔心切錯** → 小型離線 ASR 常聽錯同音字（特→各、要→優、健→鑒） → 檢查切點前後每 10 ms 的 dB；切點在 -90 dB 靜音裡就沒問題。
25. **臨時 TTS 版長度 65 秒，超過規格** → Kokoro 在 speed 1.05 時比子墨慢約 30% → 改成 speed 1.3，草稿長度才接近真人版（55 秒 vs 56 秒）。

### 流程
26. **只能等使用者的錄音才開工？** → 不必。先用臨時 TTS 把畫面、聲音、QA、輪播全部做完、截圖給使用者確認。收到錄音後只要重跑。
27. **改一個地方就重跑整條管線（約 7 分鐘）** → 先 `render.js check`，再用 `stills` 或 `cards` 抽幾格確認，最後才跑 `make.sh`。只改聲音時，只重跑 `audio.py` 加 ffmpeg mux，不必重新渲染畫面。
