### 自費項目都是制度中真實存在的

| 例子 | 制度依據 |
|---|---|
| 新藥 | 藥品要依「全民健康保險藥物給付項目及支付標準」收載後，健保才會給付；還沒收載的新藥要自費。依報導，一般新藥從申請到生效的中位數約 10 個月，癌症新藥約 13 個月 |
| 特殊醫材自付差額 | 全民健康保險法第 45 條：健保給付的特殊材料可以訂給付上限；醫師認定有醫療上需要、病人選用時，自付差額 |
| 單人病房差額 | 全民健康保險法第 51 條第 9 款：「病房費差額」不列入健保給付範圍 |
| 收入中斷 | 健保給付的是醫療服務，不包括生病期間的收入損失。旁白只說「收入也可能中斷」，不宣稱其他制度都沒有給付 |

## 每個場景的動態事件

1. **封面**：`$1,043,447,000,000` 分三行從上往下砸下來，每行落地時畫面震一下；16 位數字逐位滾動定格，最後整組數字「重擊」一次。「自己準備醫療費」用朱紅字，並手寫畫底線。
2. **拆掉直覺**：手寫「≠」、分割線從上往下畫出。左邊是 114/115/116 年度健保總額長條圖（真實數字，從 0 起算）加上青綠上升箭頭；右邊錢包一張張飛出鈔票，越來越薄。
3. **生活場景**：依旁白依序畫出四個圖示。藥瓶彈出膠囊；支架撐開、價格牌擺動；單人病房的「1」號門牌搖晃；時鐘秒針走幾下後停住，變成暫停符號，薪資單金額欄空白。最後一句出現在正中間，四個朱紅標籤同時跳一下。
4. **核心觀念（最慢、最細）**：大傘（健保）撐開，一家四口站在傘下。雨一直下，打在傘面會濺起水花；水沿著傘面往兩側流，在傘緣聚成水滴、脫落、依重力加速落下：右邊滴進「現金流」水桶，濺起水花和漣漪，水位（朱紅）逐漸升高；左邊落到地面。第二句出現時，水桶被朱紅手繪圈圈起來。
5. **收尾 CTA**：保單翻開，筆把「保多少？」劃掉，再手寫出青綠色「誰付？」並畫底線。CTA 停留 3 秒，片尾小字列出資料來源。

## 聲音

| 項目 | 做法 |
|---|---|
| 配樂 | `tools/audio.py` 程式合成的原創曲：104 BPM，Am7–Fmaj7–C–G；加法合成鋼琴、合成大鼓、rim、hi-hat。封面第 0 格就下和弦，搭配 hi-hat 快速律動；第 4 張拿掉打擊，改成半速和弦加 pad；CTA 收在 C 大調和弦加鐘聲 |
| 音效 | 數字滾動 tick、落地 thump、重擊、鉛筆塗寫、分割線 zip、鈔票飛出、膠囊彈出、時鐘滴答、停止、雨聲、傘撐開、水滴落桶（桶越滿音越高）、翻頁、筆劃掉、手寫 |
| 同步 | 音效時間由 `node tools/render.js events` 從 `render/scenes.js` 的 `EVENTS` 匯出，和畫面用同一組時間函式 |
| 混音 | 旁白時音樂自動壓低 10 dB、音效壓低 5 dB；整體 -15 LUFS，限幅器上限 -4.2 dBFS，讓 AAC 編碼後的真峰值維持在 -1.5 dBTP 以下 |

## 製作流程

```bash
npm install            # 字型（芫荽 Iansui）與 playwright 1.56.1（對應預裝的 Chromium）
pip install sherpa-onnx soundfile numpy scipy pyloudnorm imageio-ffmpeg pillow opencc-python-reimplemented
# 模型：MODELS_DIR 底下放 kokoro-multi-lang-v1_1（備用 TTS）與 sherpa-onnx-paraformer-zh-small-2024-03-09（校對用 ASR）
./make.sh
```

1. `tools/split_voice.py`：把 VoAI 一次生成的整段音檔，依字數比例和停頓長度用動態規劃切成 13 句，並逐句用離線 ASR 驗證
2. `tools/tts.py`：量測每句實際秒數，依 `script.json` 每場景的 lead/gap/tail 排出 `build/timeline.json`（第 4 張停頓較長）
3. `tools/asr_check.py`：離線語音辨識回聽，跟稿子逐句比對
4. `tools/render.js events` → `tools/audio.py`：音效與配樂
5. `tools/render.js video 4`：Headless Chromium 逐格組 SVG，等兩次 `requestAnimationFrame` 確認畫面繪製完成才截圖，PNG 無損送進 ffmpeg
6. `tools/srt.py`、`tools/render.js cards`：字幕與輪播圖
7. `tools/qa.py`：逐格解碼，檢查空白或單色畫面、純黑/純白破圖區塊、凍結畫面、非轉場的突兀跳動，並核對總格數
